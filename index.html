Student Mobile App REST API & Result Release Gate

Students upload answer scripts from the external Student Mobile App using the REST endpoints below. Evaluated scores are automatically held (UNDER_FACULTY_REVIEW) until the Academy Admin confirms flagged scripts and publishes the examination.

GET /api/mobile/exams — List active academy exams for mobile upload
POST /api/mobile/submissions — Multipart upload (file, rollNo, candidateName, examCode)
GET /api/mobile/results/:rollNo — Held until exam is published & script confirmed
POST /api/mobile/disputes — Submit student transcript dispute (creates v2+ & re-flags)
